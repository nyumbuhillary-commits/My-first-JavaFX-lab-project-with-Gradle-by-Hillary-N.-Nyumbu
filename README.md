JavaFX Lab 1

Description

This project is my first JavaFX application created as part of the JavaFX Lab.

The lab involved installing and using:

- Java JDK 21
- IntelliJ IDEA
- Git
- Gradle
- JavaFX

Application

The application displays a JavaFX window with a welcome message and a button. When the button is clicked, the message changes.

Technologies Used

- Java 21
- JavaFX 21
- Gradle
- IntelliJ IDEA
- Git

How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 21 is selected.
4. Open the terminal in the project folder.
5. Run:

gradle run

The JavaFX application should open.

Lab Requirements Completed

- Java JDK 21 installed
- IntelliJ IDEA configured
- Git configured
- Gradle configured
- JavaFX application created
- JavaFX button interaction implemented
